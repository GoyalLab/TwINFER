# simulation_code — heterogeneity_vs_regulation

Simulations behind the six scenarios of this figure. Raw outputs are symlinked in
`final_figure_data/heterogeneity_vs_regulation/simulation_data/`.
The scripts are the ones that generated the data, with paths adapted to this layout and the documentation rewritten; tested only with small smoke runs (no full rerun).

## 1. Single-state and 2-state scenarios — `simulation_data/single_and_two_state_simulations/`
Generated by yscher, 1,000 replicates per configuration (A_B, A_B_low_k_on, A_B_high_k_on, A_to_B, A_to_B_low_k_on, A_to_B_high_k_on).
Single-state = A_B / A_to_B; 2-state = a low_k_on and a high_k_on replicate of the same number paired.

| File | Role |
|---|---|
| `simulation_configs.py` | Settings of the six configurations (`get_base_configs`); from yscher's `figure_2_simulations.py` (upstream commit `b4bb9cb`), settings unchanged |
| `simulate_heterogeneity_and_regulation.py` | Runs a range of replicates of one configuration with the twinfer simulator (was yscher's `generate_simulation_set.py`) |
| `run_generate_replicates_0_99.sbatch` | SLURM array for replicates 0-99 (array 8265202, 600 tasks) |
| `run_generate_replicates_100_999.sbatch` | SLURM array for replicates 100-999 (5,400 tasks) |

Settings: 6,000 cells before division (= 6,000 twin pairs); 1,000 h burn-in; twins simulated 48 h after division, sampled hourly; additive multiple-interaction model;
connectivity matrices and `median_parameter.csv` from `input_folder`. Parameter rows (`median_parameter.csv`): single state rows [0,1] (k_on 0.66);
low_k_on row 2 (k_on 0.12); high_k_on row 3 (k_on 1.66). One replicate per array task.

## 2. Drift scenarios — `simulation_data/drift_lowhigh_Kramp/` (A_B, A_to_B)
Generated by us (2026-10-01), 1,000 replicates per network.

| File | Role |
|---|---|
| `simulate_drift_lowhigh_Kramp.py` | Drift simulation (needs `twinfer.simulation.gillespie_drift` from `package/`) |
| `run_simulate_drift_lowhigh_Kramp.sh` | SLURM launcher: 3 array tasks (A_B reps 0-999; A_to_B reps 0-499 and 500-999) |

Settings: the burn-in end state of replicate n is reused from the single-state set above (`single_and_two_state_simulations`), so replicate n starts from the same parents.
At division the 6,000 parents split 50/50 into clones (twins share fate): low half (clone_id 0-2999) ramps k_on 0.66 -> 0.12, high half (clone_id 3000-5999) ramps 0.66 -> 1.66,
both linearly over tau = 10 h from division, k_on of both genes scaled. For A_to_B the Hill K of gene_1 -> gene_2 tracks the live mean-field value (updated every 0.05 h; "Kramp");
A_B has no regulation, so it is a plain k_on ramp. Twins run 48 h after division, sampled hourly.
Command: `simulate_drift_lowhigh_Kramp.py --network <NET> --out-dir <OUT> --reps <range> --jobs 12 --cores-per 4 --twin-time 48 --tau 10 --burnin-hours 1000 --dt-K 0.05`.
Each output folder has a `log.jsonl` with the per-replicate settings. Checked: A_B replicate 0 mean gene_1 mRNA plateaus at 1.9 (high) / 0.2 (low) vs 0.8 at division,
matching the steady state expected from the k_on values.

## Inputs
Connectivity matrices (`connectivity_matrix_2_gene_no_interaction.txt`, `connectivity_matrix_A_B.txt`, `connectivity_matrix_A_to_B.txt`) and `median_parameter.csv` are in
`final_figure_data/heterogeneity_vs_regulation/input_folder/` (override with `INPUT_DIR`). They are the files the simulations were made with
(yscher's `TwINFER_tip`, b4bb9cb). The repo's `simulation_example_input_data/median_parameter.csv` has one extra row (row 6); rows 0-3 used here are identical.
Output of the single/2-state generator: `OUT_DIR` (default `simulation_data/single_and_two_state_simulations`; that folder is a symlink to yscher's set, so set `OUT_DIR` before regenerating).
Launchers need `source code/TwINFER/env.sh` first (sets `TWINFER_PROJECT_ROOT`, `TWINFER_CODE_ROOT`, `TWINFER_PYTHON`).
